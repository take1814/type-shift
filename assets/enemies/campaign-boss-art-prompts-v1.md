# TYPE SHIFT 六大ボス画像生成プロンプト v1

## 共通指定

- 用途：戦闘画面と敵図鑑で使用する高精細な敵キャラクター素材
- 方向性：完全オリジナルのダークファンタジーJRPG、写実寄りの重厚なコンセプトアート
- 構図：敵1体のみ、全身、中央配置、四辺に十分な安全余白、左向きの斜め構図
- 光：TYPE SHIFTの世界観に合わせたシアンのリムライト
- 背景：背景分離用の完全な単色グリーン
- 禁止：文字、ロゴ、UI、透かし、額縁、手足や翼の見切れ、既存作品の固有意匠

## 個別指定

| 敵 | 生成時の主題 |
|---|---|
| 虚無の機械神ガイアス | 黒いルーン装甲、非対称な四本の機械腕、胸部の虚無核、分解した文字機構 |
| 混沌の闇竜ヴォルカリオン | 黒曜石の鱗、紫水晶の角、侵食したルーン亀裂、崩れたエネルギー翼 |
| 翠風の守護者セレスティア | 女性型の古代樹守護神、枝角、樹皮と翡翠結晶の装甲、葉の外套 |
| 紅蓮の炎獣アグニロス | 獅子と竜を合わせた巨獣、黒曜石の外殻、溶岩亀裂、炉心、炎の角 |
| 氷晶の支配者フロストノヴァ | 長身の氷晶君主、半透明の結晶装甲、氷冠、長い外套、氷槍状の突起 |
| 雷天の魔導皇ライディンガルド | 浮遊する魔導皇、黒と白の儀礼装甲、黄金の機械光輪、六つの雷文字環 |

## 出力後処理

生成画像からグリーン背景をソフトマットで除去し、発光、炎、結晶の半透明輪郭を残したPNGとして保存する。
