# TYPE SHIFT 武器正式素材・生成記録 v1

> 作成日: 2026-07-22  
> 生成方式: Codex組み込み画像生成  
> 用途: 育成画面、武器図鑑、キャラクター装備欄、戦闘装備表示

## 共通アートルール

- `Art_Bible_v1.1_仲間救出改定.md` の第9章を基準とする。
- 武器は「世界を書くための筆記具」として設計する。
- 黒染め鋼、ルーンガラス、ブラケット形の鍔、カーソル形の柄頭を共通DNAとする。
- 背景はダークUIへなじむ墨黒からミッドナイトネイビーの放射背景とする。
- 武器全体を画面内へ収め、手、人物、台座、ロゴ、透かし、可読文章を入れない。
- 既存作品の武器、紋章、固有シルエットを模倣しない。

## 旅立ちの剣

保存先: `starter-v1.png`

生成要点:

- 細身の片手剣
- 冷たい黒染め鋼
- シアン白に光る細いルーンガラスの背骨
- 片側へずれた開きブラケット形の小型鍔
- 暗い革巻きと煙ガラスのカーソル型柄頭
- 静かで正確な初期シフトブレード

## ルーメン・エッジ

保存先: `lumen-v1.png`

生成要点:

- 旅立ちの剣から系譜を感じる光属性の進化形
- 月白のルーンガラスと抑制した記憶金
- 二重の細いブラケット弧
- 整列して上昇する幾何学文字片
- 豪華さよりも復元・威厳・精密さを優先

## 疾風の剣

保存先: `gale-v1.png`

生成要点:

- 高速入力向けの軽量な片手剣
- 前方へ流れる細い湾曲刃
- 文字間隔のずれを示す分割溝
- 煙紫のルーンガラスと最小限のシアン整列線
- 紫は汚染・影の機能部分へ限定

## 共鳴の大剣

保存先: `resonance-v1.png`

生成要点:

- 削除と再記述を表す両手大剣
- 刀身中央に大きなネガティブスペース
- 並行する2本のコーラル赤ルーンガラス
- 左右で共鳴する幾何学文字片
- 炎そのものは描かず、発光を機能部へ限定

## 実装上の視覚差分

| 状態 | 表示 |
|---|---|
| 未入手 | 正式素材をグレースケール・低輝度化 |
| +1〜+4 | 強化値表示と弱い外周光 |
| +5〜+9 | 発光境界とオーラを強化 |
| +10以上 | ルーンコア色の境界と最大オーラ |
| 装備中 | `EQUIPPED` 表示、キャラクター画面と戦闘画面へ同期 |

## 戦闘キーアート差分

装備武器を切り替えた際に、戦闘画面のレンが持つ武器と斬撃軌跡も同じデザインへ切り替える。レンの顔、髪型、衣装、身体比率、戦闘姿勢、画角、敵、背景、UI用の余白は共通とし、武器と武器由来の発光色だけを変更する。

| 装備武器 | 戦闘用素材 | 主な演出色 |
|---|---|---|
| 旅立ちの剣 | `../battle-ren-aster-v2.png` | シアンブルー |
| ルーメン・エッジ | `../battle-ren-lumen-v1.png` | 月白・記憶金 |
| 疾風の剣 | `../battle-ren-gale-v1.png` | 煙紫・シアン |
| 共鳴の大剣 | `../battle-ren-resonance-v1.png` | コーラル赤・暗赤 |

### 再利用可能な編集プロンプト

```text
画像1を編集対象、画像2を装備武器の厳密なデザイン参照として使用する。
画像1のレン・アスターの顔、黒髪とシアンの毛先、衣装、身体比率、表情、戦闘姿勢、背景、敵、画角、ライティング、UI用の余白を維持する。
レンが持つ武器だけを画像2の武器へ置き換え、刃の比率、鍔、柄、ルーンガラス、発光色を一致させる。
斬撃軌跡と周囲の文字粒子は新しい武器のルーンコア色へ合わせる。
既存作品の意匠、ロゴ、透かし、読める文章、新しい人物、余分な腕や武器を追加しない。
高精細な商用ダークファンタジーJRPGの戦闘キーアートとして完成させる。
```
