# TYPE SHIFT 開発版

TYPE SHIFTは、「文字が世界を構成する魔法コードである」という世界観を持つ、ブラウザ向けタイピングRPGです。見た目はArt Bible、処理は実装仕様書に沿って制作しています。

設計書の参照順は、[TYPE_SHIFT 設計書インデックス](../TYPE_SHIFT_設計書_INDEX.md)を基準にしてください。

## 現在の実装内容

### タイピング

- 英単語を使用した出題
- 文字単位の正誤判定
- WPM、正確率、コンボの計測
- 英字、数字、記号を含む48キーの習熟記録
- 苦手キーを出題へ反映する適応学習

### 戦闘

- 正しい1打鍵ごとの攻撃と敵HP減少
- 単語完成時の強攻撃
- 高速連続入力でも毎回再生される攻撃演出
- Burst、属性相性、敵特性、敵反撃
- 主人公と敵のHP、ダメージ、被弾、画面振動
- 主人公の待機画・攻撃画を重ねた安定表示
- 背景、キャラクター、霧、接地影、エフェクトを分離した戦闘レイヤー
- クエスト最後の敵に対する0.75倍速の `FINISHING SHIFT`
- 最終敵消滅後のWIN表示とEnter待機
- 物語最終ボス専用の `FINAL SHIFT / REWRITE`

### RPG・物語

- 3章→6ステージ→各5クエストのキャンペーン選択UI
- 2ステージごとの王戦と、三王撃破後に解放される「神への挑戦」
- クエストを順番に解放する進行判定とキャンペーン進捗表示
- 雑魚20、小ボス10、中ボス10、属性変異20、特殊種20の敵台帳
- 6体のステージ大ボスと、三王・創世神を含む全90体の敵定義
- 6大ボスの専用高精細・背景分離済み戦闘素材
- 全90体の固有戦利品、レアリティ、ドロップ率、出現ステージ
- レベル、XP、Gold、SP
- 4種の武器と装備・強化・進化
- 3系統、全12スキルのスキルツリー
- 6人の仲間をステージごとに救出、最大2人の同行、支援、親密度
- レンが兄、ノクスが弟という生き別れの兄弟物語
- 希少仲間センリンの「静・流・識」三試練
- 6人加入・三王撃破後に解放される創世神4フェーズ戦とORIGIN SHIFT

### 継続・記録

- 敵、戦利品、武器、仲間、実績・デイリーの図鑑
- 戦利品の所持数保存とクエスト結果での獲得表示
- 実績18種、称号9種（六界・30クエスト・三王・創世神の個別判定）
- デイリーミッションと連続起動記録
- 序章・六界・三王・神域・終章を収録した12件の進行連動型物語アーカイブ
- ローカル保存
- セーブデータの書き出し・読み込み
- 入力統計、装備、スキル、キャンペーン、仲間、戦利品を対象とした保存整合性検証
- 敵90体の標準データ契約（ステージ参照、倍率、能力、アート、配置情報）
- Web Audioによる効果音と画面・戦闘別BGM
- PWAとオフライン起動

## 起動方法

`index.html` はJavaScriptモジュールを使用するため、ローカルWebサーバー経由で開いてください。

- 開発プレビュー: `http://127.0.0.1:4182/`
- `file://` での直開きは、モジュールとキャッシュの制約により正式な確認方法ではありません。

## 既知の差異

高精細画像は初回表示時の負荷を抑えるため、図鑑・仲間・武器画面では遅延読み込み、戦闘中の表示だけ即時読み込みにしています。

- 6ステージ固有背景、三王専用戦闘、創世神4フェーズ戦、三王と創世神の個別キャラクター素材は実装済みです。
- 雑魚、小ボス、中ボス、属性変異、特殊種は全90体のデータを実装済みです。通常敵80体すべてを固有高精細アートへ置換済みです。ステージ1〜3の通常敵・上位敵・属性変異を図鑑、戦闘、オフラインキャッシュへ接続済みです。
- 仲間画面と救出イベントは新6人構成へ統合済みで、旧ヴェイル記録は互換領域へ保存します。
- 6大ボス、三王、創世神は固有アート実装済みです。通常敵の固有アート進捗は80 / 80体です。
- 高精細画像を多数扱うため、初回キャッシュと非表示画像の読み込みは今後さらに軽量化できます。

詳細は実装仕様書v5.0の「実装順序」と「受入条件」を参照してください。
